Quick Start

Ce guide sert de point d’entrée. Il vous montre le flux minimal (charger → sélectionner → imager → afficher). Il vous indique aussi où trouver les détails.

  • Pour les unités, indices et conventions : voir Concepts & conventions.
  • Pour des scripts complets reproductibles : voir les Tutoriels A→Z.
  • Pour les signatures/arguments/exemples officiels : voir la Référence API.

En quatre lignes

Objectif : produire une première image, sans régler tous les paramètres.

from difmap_wrapper import DifmapSession

with DifmapSession() as session:
    session.observe("data/source.uvfits")
    img = session.imager.make_dirty_map(size=512, cellsize=0.1, pol="I")
    session.vis.plot_image(img, cmap="inferno")

make_dirty_map enchaîne select → mapsize → invert en un seul appel — inutile d’appeler select() séparément. Le bloc with garantit le nettoyage même si une exception se produit.

Les trois sous-objets

Vous utilisez toujours ces trois objets.

Attribut Type Rôle
session.obs Observation Données UV, sélection de polarisation, flagging, sauvegarde
session.imager DifmapImager Grille d’image, pondération UV, FFT, récupération de l’image
session.vis Visualizer Graphiques statiques Matplotlib (UV, radplot, carte)

Schéma du flux le plus courant :

DifmapSession
  ├─ obs    : observe() → select() → (flag/save)
  ├─ imager : mapsize() → (uvweight/uvtaper) → invert() → get_map_package()
  └─ vis    : uvplot()/radplot()/plot_image()

Charger et explorer les visibilités

Objectif : comprendre ce que contient le fichier (UV, amplitude/phase, flags).

session.obs.get_data() renvoie un dictionnaire de tableaux NumPy.

  • u, v : coordonnées UV en longueurs d’onde (λ)
  • amp, phase : amplitude (Jy) et phase (degrés)
  • weight : poids statistique (≤ 0 = flaggé)

Pour un exemple complet d’analyse (filtrage, stats, plots), voir :

  • Tutoriel 2 — Flagging programmatique

Graphiques de visibilités

Objectif : vérifier rapidement la couverture UV et repérer des données aberrantes.

with DifmapSession() as session:
    session.observe("data/source.uvfits")
    session.obs.select(pol="I")

    session.vis.uvplot()     # plan (U, V) en Mλ, conjugués inclus
    session.vis.radplot()    # amplitude vs rayon UV

Pipeline d’imagerie étape par étape

Objectif : garder la main sur la pondération et le taper.

Si vous voulez contrôler la pondération/taper, la séquence est :

  1. mapsize(size, cellsize)
  2. uvweight(...) (optionnel)
  3. uvtaper(...) (optionnel)
  4. invert()
  5. get_map_package(cellsize=...)

Le package retourné par get_map_package() contient l’image (data), le faisceau (beam_data) et un extent déjà prêt pour Matplotlib.

Pour un script complet, voir :

  • Tutoriel 1 — Produire une Dirty Map

Afficher l’image manuellement avec Matplotlib

Objectif : tracer vous-même l’image, sans passer par Visualizer.

get_map_package() retourne un dictionnaire avec data (tableau NumPy 2D) et extent (tuple [xmin, xmax, ymin, ymax] en mas, prêt pour imshow).

import matplotlib.pyplot as plt
from difmap_wrapper import DifmapSession

with DifmapSession() as session:
    session.observe("data/source.uvfits")
    session.obs.select(pol="I")
    session.imager.mapsize(512, 0.1)
    session.imager.invert()
    img = session.imager.get_map_package(cellsize=0.1)

fig, ax = plt.subplots(figsize=(8, 8))
ax.imshow(img["data"], extent=img["extent"], origin="lower", cmap="inferno")
ax.set_xlabel("Décalage RA (mas)")
ax.set_ylabel("Décalage Dec (mas)")
plt.colorbar(ax.images[0], ax=ax, label="Intensité (Jy/beam)")
plt.show()

origin="lower" est requis : sans lui, l’axe Dec est inversé. extent est déjà en mas, centré sur la phase center — pas besoin de conversion.

Voir aussi la Référence API pour get_map_package et get_cropped_map.

Gestion des erreurs

Objectif : distinguer une erreur d’usage (séquence) d’une erreur du moteur.

from difmap_wrapper.exceptions import DifmapStateError, DifmapError

with DifmapSession() as session:
    try:
        session.imager.invert()   # sans observe() → DifmapStateError
    except DifmapStateError as e:
        print(f"Erreur d'état : {e}")
    except DifmapError as e:
        print(f"Erreur moteur C : {e}")
Exception Déclenchée quand
DifmapStateError Opération hors-séquence : invert() sans mapsize(), observe() non appelé, session déjà active
DifmapError Le moteur C retourne une erreur : fichier corrompu, grille invalide, échec FFT

DifmapStateError est un sous-type de DifmapError — un seul except DifmapError intercepte les deux.

Le singleton : une session par processus

Objectif : éviter l’erreur “Une instance est déjà active”.

Le moteur C utilise des variables globales static. Une seule DifmapSession peut être active à la fois par processus.

# ✗ — Lève DifmapStateError
s1 = DifmapSession()
s2 = DifmapSession()   # → "Une instance est déjà active"

# ✓ — Séquentiel : fermer avant d'ouvrir
s1.cleanup()
s2 = DifmapSession()

# ✓ — Recommandé : bloc with (cleanup automatique)
with DifmapSession() as session:
    session.observe("source1.uvfits")
# ← ici s1 est fermée, on peut en ouvrir une nouvelle

with DifmapSession() as session:
    session.observe("source2.uvfits")

Pour traiter plusieurs fichiers en parallèle, voir Traitement batch — le DifmapBatchManager lance des processus OS séparés, chacun avec son propre singleton.

Utilisation dans un notebook

Objectif : éviter un état incohérent si vous relancez des cellules.

from difmap_wrapper import DifmapSession

with DifmapSession() as session:
    session.observe("data/source.uvfits")
    session.obs.select(pol="I")
    img = session.imager.make_dirty_map(512, 0.1)
    session.vis.plot_image(img)
Tip

Dans un notebook, préférez un bloc with par étape (chargement, imagerie, export). Cela limite les erreurs après une interruption.
